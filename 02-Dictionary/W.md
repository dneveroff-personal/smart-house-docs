
# Wiren Board
#wiren-board
🌐 https://wirenboard.com
Внешняя Wiki https://wiki.wirenboard.com/wiki/Documentation

Wiren Board — группа компаний, которая с 2013 года разрабатывает и производит оборудование для автоматизации, диспетчеризации и мониторинга.

## Контроллеры
Производит универсальные контроллеры автоматизации, работающие под управлением свободного программного обеспечения. Применяются в задачах мониторинга серверного и климатического оборудования, диспетчеризации и сбора данных с приборов учёта, в качестве основы для «умного дома» и автоматизации производств.

- [Wiren Board 8.5](https://wiki.wirenboard.com/wiki/Wiren_Board_8.5 "Wiren Board 8.5") — мощный универсальный контроллер для любых задач.
- [Wiren Board 7](https://wiki.wirenboard.com/wiki/Wiren_Board_7.4 "Wiren Board 7.4") — универсальный контроллер для любых задач.
- [Wiren Board 8M](https://wiki.wirenboard.com/wiki/Wiren_Board_8M "Wiren Board 8M") — версия контроллера в металлическом корпусе.
